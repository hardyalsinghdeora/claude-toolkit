# Output/worklog/ — daily work logs (local-only)

Auto-generated by `bin/worklog` at **zero token cost** from the
csession session index + git commits. One file per active day; days with no
activity (weekends, leave) simply have no file.

Committed here: only this README. The logs themselves are personal work
history and stay local.

## File format (machine-readable for report generation)

```markdown
---
date: 2026-01-15
sessions: 6
commits: 3
transcript_tokens: 310000
projects: [my-service, my-ui]
---

# Work Log — 2026-01-15

## Sessions
- 09:12  **my-service** — Implement rate limiting (4 tasks, ~80k tok)

## Commits
- my-service: a1b2c3d add token bucket middleware

## Files touched
- src/middleware/rateLimit.ts

## Flags (auto)
- Session abcd1234 ran ~180k tokens — consider /clear between task pivots…

## Summary            <- added by the worklog skill (AI narrative)
## Coaching           <- added by the worklog skill (improvement advice)
```

## Lifecycle

- **launchd automation** runs `worklog check` at login (backfills the last 7
  days — covers weekends/long offs) and daily at 21:15 (writes today's log).
- `worklog week` aggregates 7 days into `week-<date>.md` — the input for
  weekly mails / monthly reviews via the `worklog` skill.
